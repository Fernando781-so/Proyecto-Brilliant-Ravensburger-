# Imágenes de la aplicación

Esta carpeta está registrada en `pubspec.yaml` para las imágenes de la app.

## Imagen de fondo de la pantalla inicial

Coloca tu imagen en esta carpeta (`assets/images/`) con cualquiera de estos nombres:
- `fondo_inicio.png` *(prioridad 1)*
- `fondo_inicio.jpg` *(prioridad 2)*
- `fondo_inicio.webp` *(prioridad 3)*

Si todavía no has agregado una imagen, la pantalla inicial mostrará un fondo ilustrativo decorativo de respaldo automáticamente.
